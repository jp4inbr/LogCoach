# LogCoach

Análise de logs de WoW com coach de IA.

Cole o link do seu log do Warcraft Logs e descubra, em português, os erros que mais estão custando dano, comparando a sua luta com os melhores jogadores do mundo no mesmo chefe. O que levaria horas de análise manual no Warcraft Logs vira uma leitura de poucos minutos.

Trabalho A3 de Usabilidade de Software — Engenharia de Software, UNA.

## Documentação

Toda a documentação do projeto está em [`docs/`](docs/README.md), sincronizada com o GitBook do grupo.

## Stack

- Frontend: React + Vite
- Backend: FastAPI (Python)
- IA: Gemini via Vertex AI (Google Cloud)
- Dados: API do Warcraft Logs v2
